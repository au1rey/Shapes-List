# Shapes and Inheritance
## Description 
This C++ program allows users to create and manage lists of 2D and 3D shapes. It offers functionalities to add, remove, search, display, sort, scale, and find the largest and smallest shapes in each list. The program also uses inheritance to manage the relationships between different shapes (e.g., Shape, Shape2D, Shape3D) for a more flexible and scalable structure.

## Key Features
2D and 3D Shape Lists: Manage separate lists for 2D and 3D shapes.

Shape Operations: Add, remove, search, display, sort, and scale shapes.

Largest and Smallest Shapes: Show the largest and smallest shapes in each category.

Inheritance: Base class Shape with derived classes like Shape2D, Shape3D, and specific shape types such as Square, Circle, Triangle, etc.
